# Data Card: UCI Adult Dataset

* **Source:** UCI Machine Learning Repository, fetched via OpenML (version 2).
* **License:** Creative Commons Attribution 4.0 International (CC BY 4.0).
* **Size:** 48,842 rows, 15 columns.
* **Known Biases:** The dataset overrepresents demographic majorities and reflects 1994 Census income disparities. Features such as `race` and `sex` must be monitored to prevent algorithmic discrimination.
* **Privacy Concerns:** While anonymized, combinations of granular demographic variables (age, occupation, native country, marital status) present theoretical re-identification risks in small populations.
